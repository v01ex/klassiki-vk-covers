# Запрос доступа к API обложки личного профиля

Получатель: devsupport@corp.vk.com

Тема: Доступ photos для установки обложки личного профиля — VK Mini App 54807558

Здравствуйте!

Разрабатываем VK Mini App «Обложки от СПО Классики», ID 54807558:
https://vk.ru/app54807558

Прототип: https://v01ex.github.io/klassiki-vk-covers/

Пользователь выбирает одну из 12 готовых обложек отряда и самостоятельно нажимает кнопку установки в свой личный профиль. Требуется менять именно обложку профиля. Автоматических фоновых изменений не планируем.

В документации photos.saveOwnerCoverPhoto указано, что метод поддерживает обложку профиля пользователя, а право photos для пользовательского ключа выдаётся в исключительных случаях через обращение в поддержку.

Просим уточнить:

1. Можно ли предоставить нашему Mini App право photos для установки обложки личного профиля и какие условия для этого нужно выполнить?
2. Как правильно получить адрес загрузки для личного профиля через photos.getOwnerCoverPhotoUploadServer? Описание метода получения адреса упоминает сообщество, а метод сохранения — также профиль пользователя.
3. Допустим ли этот сценарий через VKWebAppGetAuthToken и VKWebAppCallAPIMethod, или требуется другая официальная интеграция?

Первый диагностический запуск вернул код 10; исходный отчёт не сохранил тип ошибки и этап сбоя, поэтому мы пока не связываем его с конкретным методом. Обновили диагностику, чтобы отдельно проверить авторизацию, users.get и получение адреса загрузки обложки.

Спасибо!
